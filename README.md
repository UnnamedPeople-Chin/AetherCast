# 🌌 AetherCast - Interactive Hand Tracking & Celestial Magic Sandbox

AetherCast (Air Magic) is a high-performance, real-time Interactive Hand Tracking & Visual Magic Engine built with HTML5 Canvas 2D, Electron, and MediaPipe Hands. It turns hand gestures into cinematic visual spellcasting effects at uncapped 60–144+ FPS.

---

## ✨ Features & Magic Gestures

- 🌌 **Interstellar Gargantua Blackhole** *(Gesture: Fist / Mengepal)*:
  - Solid pitch-black event horizon void (`#000000`) surrounded by palette-adaptive gravitational lensing accretion rings.
  - **3.8-Second Full Charge** duration with supernova explosion release (min 50% charge required).
  - 3.0-second cooldown delay post-explosion.

- 🛡️ **Doctor Strange Magic Shield** *(Gesture: Open Palm + Wrist Rotation 90°)*:
  - Dual rotating mandala runes with sparks and ancient glyphs.
  - Requires deliberate **Wrist Rotation (90° Twist)** to trigger, completely preventing accidental popups during natural hand resting.

- 🔮 **Floating Cosmic Energy Orb** *(Gesture: Single Pinch Tap / Jempol + Telunjuk)*:
  - Triggered by a single tap between thumb & index fingertips.
  - Persists continuously and floats right above the index fingertip as your hand moves freely!

- ⚡ **Giga Dual-Hand Fusions**:
  - **2 Fists Rapat** → Supermassive Giga Blackhole & Mega Supernova Explosion.
  - **2 Open Palms Rapat** → Multiverse Giga Shield Array.

- 🚀 **Ultra-High Performance Architecture (60–144 FPS)**:
  - **Decoupled Offscreen Tracking Loop (480x270)**: Reduces MediaPipe WASM processing to 7ms, eliminating main thread frame drops.
  - **Batched Particle Path Rendering**: Groups 500+ particles into 4–5 GPU draw calls instead of 500 individual paths.
  - **Delta-Time Normalization**: Guarantees silky smooth animation speed across 60Hz, 120Hz, or 144Hz monitors.

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/UnnamedPeople-Chin/AetherCast.git
   cd AetherCast
   ```

2. **Install Electron Dependencies**:
   ```bash
   npm install
   ```

3. **Launch Desktop Application**:
   ```bash
   npm start
   ```

Or open directly in browser via any HTTP server (`http://localhost:8080`).
